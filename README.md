# Embedded Timer

Notion などに埋め込んで使うためのカウントダウンタイマー。ビルド不要の静的ファイル (`index.html` / `style.css` / `script.js`) だけで動く。

## 使い方

- 時間表示をクリックすると時間を入力できる (`25` = 25分、`1:30` = 1分30秒、`1:00:00`、`1h30m`、`90s` なども可)
- プリセットのボタンで時間を切り替えられる
- `−10分` / `−1分` / `+1分` / `+10分` のボタンで残り時間を増減できる (動いている間も使える。0 以下になる操作はできない)
- キーボード: `Space` で開始 / 一時停止、`R` でリセット
- 終了するとアラーム音が鳴り、表示が点滅する
- 「リセット」の右にあるリンクボタンで、今の時間設定と URL パラメータを反映した埋め込み用リンクをコピーできる (コピーできない環境では、リンクを選択した状態で表示する)
- 状態はブラウザに保存されるため、ページを開き直しても残り時間が引き継がれる (URL ごとに別々に保存)

## URL パラメータ

| パラメータ | 例 | 内容 |
| --- | --- | --- |
| `t` | `?t=25m` | 初期の時間 (省略時は 5分) |
| `presets` | `?presets=5m,15m,30m` | プリセットボタン (空にすると非表示) |
| `label` | `?label=休憩` | 時間の上に表示する見出し |
| `theme` | `?theme=dark` | `light` / `dark` (省略時は OS の設定に従う) |
| `sound` | `?sound=0` | `0` でアラーム音を鳴らさない |

例: `https://<user>.github.io/<repo>/?t=25m&label=集中タイム&presets=5m,25m,50m`

## GitHub Pages で公開する

1. GitHub にリポジトリを作成し、このディレクトリの中身を `main` ブランチに push する
2. リポジトリの Settings → Pages を開き、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存する
3. 数分後に `https://<user>.github.io/<repo>/` で公開される

## Notion に埋め込む

1. Notion のページで `/embed` と入力し、「埋め込み」ブロックを追加する
2. 公開した URL (必要なら URL パラメータ付き) を貼り付ける
3. ブロックの高さを調整する (高さが低いとプリセットと進捗バーが隠れ、時間表示と操作ボタンだけになる)

Notion のテーマ設定は埋め込み先に伝わらないため、OS の設定と Notion のテーマが異なる場合は `theme` パラメータで指定する。
